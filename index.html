SoloKanban.

A board is a folder. A card is a file. Nothing else.

This browser can't run SoloKanban.

SoloKanban reads and writes your board directly on disk using the File System Access API, which is currently only available in Chromium-based browsers (Chrome, Edge, Brave, Opera). Please reopen this page in one of those.

Choosing an empty folder starts a new board there. Choosing a folder that already has a board.json in it opens that board.
